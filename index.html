Tuplas

1 / 12

¿Qué es una Tupla?

Una colección ordenada e inmutable de elementos. Como una lista que no se puede modificar.

2 / 12

Crear una Tupla

Se define con paréntesis (), separando los elementos con comas.

# Tupla de números
numeros = (1, 2, 3)

# Tupla de strings
vocales = ('a', 'e', 'i', 'o', 'u')
3 / 12

Tupla de un solo elemento

¡Importante! Debe llevar una coma al final para ser reconocida como tupla.

tupla_correcta = (1,)
print(type(tupla_correcta)) # 

no_es_tupla = (1)
print(type(no_es_tupla)) #
4 / 12

Acceder a Elementos

Igual que las listas, se accede a un elemento por su índice.

vocales = ('a', 'e', 'i', 'o', 'u')
print(vocales[0])  # 'a'
print(vocales[-1]) # 'u'
5 / 12

Slicing (Rebanado)

También funciona igual que en las listas para obtener una sub-tupla.

numeros = (0, 1, 2, 3, 4, 5)
print(numeros[1:4]) # (1, 2, 3)
6 / 12

La Inmutabilidad

No se pueden añadir, eliminar o modificar elementos después de su creación.

mi_tupla = (1, 2, 3)
# Esto dará un error (TypeError)
mi_tupla[0] = 99
7 / 12

¿Por qué usar Tuplas?

Para datos que no deben cambiar: coordenadas, constantes, claves de diccionario, etc.

8 / 12

Método: .count()

Cuenta cuántas veces aparece un elemento en la tupla.

mi_tupla = (1, 2, 2, 3, 2)
print(mi_tupla.count(2)) # 3
9 / 12

Método: .index()

Devuelve el índice de la primera aparición de un elemento.

mi_tupla = ('a', 'b', 'c', 'b')
print(mi_tupla.index('b')) # 1
10 / 12

Desempaquetado (Unpacking)

Permite asignar los elementos de una tupla a múltiples variables.

coordenadas = (10, 20)
x, y = coordenadas

print(f"X: {x}, Y: {y}")
11 / 12

Recorrer una Tupla (Loop)

Se usa un ciclo `for`, igual que con las listas.

for vocal in ('a', 'e', 'i', 'o', 'u'):
    print(vocal.upper())
